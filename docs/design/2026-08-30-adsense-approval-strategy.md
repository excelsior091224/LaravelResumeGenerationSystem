# 2026-08-30 Google AdSense 審査通過（合格）に向けた総合対策サマリ

## 1. 審査不合格の原因と分析

Google AdSenseより以下の理由で不合格（要確認）の通知を受領。

1. **パブリッシャーのコンテンツを含まない画面における Google が配信する広告の扱い**
2. **有用性の低いコンテンツ**

### 原因分析

- 当サービス（Resume Foundry）は単一画面のWebアプリ（職務経歴書入力・生成ツール）であるため、画面の大半が入力フォーム・操作ボタンで占められていた。
- Googleの審査クローラは「テキスト文章（解説記事やコラム）」の量をコンテンツ価値として判定するため、単なる入力ツール画面は「文章（コンテンツ）が存在しない」「有用性が低い」と機械的に誤認識されやすい。

---

## 2. 実施した総合対策（打った施策の一覧）

### 施策A: クローラおよびユーザー向けコンテンツの拡充（トップページ）

`resources/views/resume/create.blade.php` に以下の1,500文字規模のリッチテキストエリアを追加配置。

- **サービスの特徴とメリット**: 完全無料・会員登録不要・個人情報非保持・PDF/DOCX即時生成・AIアシスト。
- **かんたん3ステップの使い方**: 入力 → リアルタイム確認 → ダウンロード の手順解説。
- **よくある質問（FAQ）**: セキュリティ、提出用フォーマットの選び方、スマホ対応などQ&Aをカード形式で網羅。
- **ノウハウガイドへの回遊リンク**: 追加した解説記事カードを配置。

### 施策B: 独立した「職務経歴書ノウハウ・ガイド記事」の新規新設

クローラが回遊・インデックスできるテキスト主体の「価値あるコンテンツページ」を3ページ新設。

1. `/guides` : **職務経歴書の書き方・例文・提出マナーガイド一覧**
2. `/guides/how-to-write-resume` : **【完全ガイド】エンジニア・Web担当者のための職務経歴書の書き方とポイント** (約2,500文字)
3. `/guides/self-pr-examples` : **【職種別・例文集】面接官の目を引く自己PR・職務要約の書き方** (約2,000文字)
4. `/guides/pdf-word-submission-rules` : **職務経歴書はPDFとWordどちらが正解？提出時のマナーと注意点** (約1,800文字)

各ページへレスポンシブで視認性の高いスタイルを適用し、トップページに戻る動線・関連ガイドへの導線を完全完備。

### 施策C: サイトマップおよびナビゲーションの網羅

- `src/public/sitemap.xml` に新規開設した全ガイドページ（`/guides`, `/guides/how-to-write-resume`, `/guides/self-pr-examples`, `/guides/pdf-word-submission-rules`）を追加。
- ヘッダー (`topbar-nav`)、フッター (`footer-nav`) にガイド一覧および個別記事へのリンクを網羅。

### 施策D: テストコードおよびアセットの検証

- `tests/Feature/GuidePagesTest.php` を作成。全4つのガイドページが正常（HTTP 200）にレスポンスし、タイトルや見出しが正しく描画されることを自動テストで検証（計33テストすべて合格）。
- Viteアセットビルド (`npm run build`) もエラーなしで正常完了。

## 3. 再申請（再審査リクエスト）の手順

本修正を本番サーバーへ反映後、以下の手順でGoogle AdSenseコンソールから再申請を行います。

1. **本番環境へのデプロイ**

   ```bash
   git add .
   git commit -m "feat: AdSense審査通過のためのコンテンツ強化・書き方ガイドページ新設"
   git push origin main
   ```

   VPS上で `git pull`, `npm run build` / `docker compose build`, キャッシュクリアを実行。

2. **Google Search Console でインデックスリクエスト（推奨）**
   - Google Search Consoleにログインし、`https://resumefoundries.com/sitemap.xml` を送信。
   - `https://resumefoundries.com/guides` および `how-to-write-resume` 等のURL検査を行い「インデックス登録をリクエスト」。

3. **Google AdSenseコンソールでの再申請**
   - AdSense管理画面 ＞ 「サイト」 ＞ `resumefoundries.com` を選択。
   - 「問題を修正しました」のチェックボックスにチェックを入れる。
   - **「審査をリクエスト」** ボタンをクリック。
