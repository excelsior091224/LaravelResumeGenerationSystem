# 2026-08-30 開発進捗サマリ

## 1. 本日の到達点

Google AdSense審査で指摘された「コンテンツを含まない画面」と「有用性の低いコンテンツ」への対策を実施した。

職務経歴書生成フォームを中心とした単一画面構成から、利用方法、FAQ、独立したガイド記事、サイト内回遊を備えた構成へ拡張した。実装とローカル検証を完了し、対策版を本番環境へデプロイした。

AdSenseの審査通過はまだ確認されていないため、現時点は再審査に向けたサイト改善と本番反映が完了した段階である。

## 2. AdSense審査結果と対応方針

AdSenseから次の理由で不合格の通知を受けた。

1. パブリッシャーのコンテンツを含まない画面におけるGoogle配信広告の扱い
2. 有用性の低いコンテンツ

入力フォームと操作ボタンが中心のWebツールは、利用者にとって実用的でも、審査クローラから独立した情報コンテンツが少ないと評価される可能性がある。

このため、広告設定だけを調整するのではなく、職務経歴書の作成に役立つ説明、例文、提出方法をサイト内で読める構成へ変更した。

詳細な分析と再申請方針は[2026-08-30 Google AdSense 審査通過（合格）に向けた総合対策サマリ](./2026-08-30-adsense-approval-strategy.md)に記録している。

## 3. トップページのコンテンツ強化

`src/resources/views/resume/create.blade.php`へ次の情報を追加した。

- サービスの特徴と利用上のメリット
- 入力、プレビュー、ダウンロードまでの3ステップ
- 個人情報、料金、対応端末、PDFとDOCXの使い分けに関するFAQ
- 新設した職務経歴書ガイドへの導線
- ヘッダーとフッターのサイト内ナビゲーション

ツールを操作しない訪問者や検索クローラにも、サービスの目的、使い方、データの扱いが伝わる構成とした。

## 4. 職務経歴書ガイドの新設

ガイド一覧と3本の独立記事を新設した。

| URL                                 | 内容                                             |
| ----------------------------------- | ------------------------------------------------ |
| `/guides`                           | 職務経歴書の書き方、例文、提出マナーのガイド一覧 |
| `/guides/how-to-write-resume`       | 職務経歴書の構成と書き方の詳細ガイド             |
| `/guides/self-pr-examples`          | 職種別の職務要約・自己PR例文                     |
| `/guides/pdf-word-submission-rules` | PDFとWordの選び方、提出時の注意点                |

共通レイアウトでは、ページごとのタイトルとメタディスクリプション、GTM、AdSense、共通ヘッダー、フッターを管理する。

各記事からツール、ガイド一覧、関連ページへ移動できるようにし、記事単体で行き止まりにならない内部リンク構造を整備した。

## 5. SEOとサイト内回遊

- `src/public/sitemap.xml`へガイド一覧と3記事のURLを追加
- トップページ、ガイド、プライバシーポリシー、お問い合わせページのナビゲーションを接続
- ガイドごとに内容に対応したtitleとmeta descriptionを設定
- PCとモバイルの両方で利用できるガイド用レスポンシブスタイルを追加

これにより、検索エンジンが公開コンテンツを発見しやすく、利用者がツールと解説記事を相互に回遊できる構成となった。
